# SAMS Backend  
**Smart Attendance Management System (API)**

This repository contains the **backend API** for the **Smart Attendance Management System (SAMS)**.  
It is built with **Node.js and Express** and provides RESTful endpoints for managing students, attendance (planned), and system health checks.

This backend is designed to be:
- Beginner-friendly
- Modular and easy to extend
- Ready for deployment to a VPS

---

## 🚀 Features

- Student management (add & list students)
- Health check endpoint
- JSON-based file storage (MVP)
- Clean project structure (controllers & routes)
- Ready for GitHub and VPS deployment

> Attendance tracking, teachers, HODs, and admin modules are **planned**.

---

## 🛠 Tech Stack

- Node.js
- Express.js
- CORS
- File-based JSON storage (MVP)
